# Meridian — настольный клиент

Клиент Meridian VPN для macOS (Apple Silicon) и Windows.

Это репозиторий **только для выпуска готовых сборок** — здесь нет
исходного кода. Скачивайте файлы со страницы
[Releases](../../releases), исходники и история разработки — в закрытом
репозитории проекта.

## Установка

### macOS (Apple Silicon)

1. На странице [Releases](../../releases) скачайте файл для macOS
   (`meridian-*-darwin-arm64.*`) из последнего выпуска.
2. Откройте скачанный файл. Если macOS Gatekeeper показывает
   предупреждение «Apple не может проверить, что это приложение не
   содержит вредоносного ПО» или похожее — это ожидаемо для сборки без
   подписи Developer ID (подпись появится позже, см. раздел ниже).
   Чтобы всё равно открыть: **Системные настройки → Конфиденциальность
   и безопасность** → внизу страницы найдите заблокированное приложение
   и нажмите **«Открыть в любом случае»**. После этого подтвердите
   открытие ещё раз в появившемся диалоге.
3. Приложению для работы туннеля потребуется системная служба с правами
   администратора — при первом запуске macOS запросит пароль, это
   ожидаемо.

### Windows (amd64)

1. На странице [Releases](../../releases) скачайте файл для Windows
   (`meridian-*-windows-amd64.*`) из последнего выпуска.
2. При запуске Windows SmartScreen может показать «Windows защитила ваш
   компьютер» — это ожидаемо для сборки без подписи кода (подпись
   появится позже, см. раздел ниже). Чтобы всё равно запустить:
   нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Приложению для работы туннеля нужны права администратора — Windows
   запросит подтверждение (UAC) при запуске.

### Проверка целостности файла (необязательно, для тех, кто хочет свериться)

Каждый выпуск содержит файл `SHA256SUMS` с контрольными суммами всех
файлов сборки. Проверить скачанный файл:

```
# macOS / Linux
shasum -a 256 -c SHA256SUMS

# Windows (PowerShell)
Get-FileHash meridian-*-windows-amd64.exe -Algorithm SHA256
# сравнить вывод со строкой в SHA256SUMS вручную
```

## Про предупреждения Gatekeeper / SmartScreen

Сборки этого проекта пока не подписаны сертификатом разработчика
(Apple Developer ID / подпись кода Windows) — это дорогостоящий и не
самый первоочередной шаг для небольшого проекта на раннем этапе.
Предупреждение системы означает «эта программа не от известного
разработчика», а не «эта программа опасна» — но проверяйте, что
скачиваете файл именно с этой страницы (`github.com/JinComputers/
meridian-desktop-releases`), не с зеркал и не по чужим ссылкам.
Подпись появится по мере готовности проекта — тогда эти шаги будут не
нужны.

## Что это за клиент

Meridian — VPN-клиент. Настольная версия (это приложение) — для macOS и
Windows, использует то же ядро подключения, что и мобильные приложения
проекта.
